# Full-Stack-Web-Development

This project is a web platform dedicated to pet and farm services.

The platform offers users the opportunity to publish their own animal services, as well as to search for and use the services offered by other providers.

The goal of the project is to facilitate the promotion of services and to connect people who provide animal services with those who need them, in an accessible and easy-to-use environment.

Front-End:
https://github.com/Alexandria0/petwell_web

Back-End:
https://github.com/Alexandria0/petwell_back

Front-End: TypeScript, React, Next.js, Tailwind CSS, HTML, CSS

Back-End: C#, .NET 9, ASP.NET Core

Database: MongoDB
